# MovieGraph 2 架构与接口

Streamlit18501调用FastAPI18080，GraphStore连接Neo4j HTTP17474/Bolt17687，仅绑定本机。

节点：MovieGraphMovie(key,dataset,movieId,title,year,imdbId,tmdbId,ratingCount,averageRating)；MovieGraphGenre和Tag(key,dataset,name)；MovieGraphUser(key,dataset,userId)；内部MovieGraphState(key=current,dataset,schemaVersion=2)。三种边IN_GENRE、HAS_TAG和带rating/timestamp/datetimeUTC的RATED。

| GET路径 | 结果和参数 |
|---|---|
| /health | 数据库状态和dataset |
| /api/stats | 四类业务节点、特征/评分/总关系、类型分布、外部标识覆盖 |
| /api/movies | q≤200字符，offset≥0，limit1–100 |
| /api/movies/{id} | 详情、评分聚合、外部URL；不存在404 |
| /api/movies/{id}/graph | limit0–12，user_limit0–5，nodes/edges |
| /api/movies/{id}/recommendations | limit1–5，score及共享项 |
| /api/movies/{id}/ratings | 分布和最近20条评分 |
| /api/features/{genre或tag} | name、offset、limit，关联电影 |
| /api/users | 匿名编号、评分数、均分 |
| /api/users/{id} | offset、limit，历史和UTC时间 |
| /api/users/{id}/recommendations | limit1–10，supportingUsers、peerAverageRating、exampleUsers |

参数错误422，未知电影或用户404，数据库不可用503。exampleUsers最多5个，supportingUsers为全部不同支持用户数。当前版本过滤dataset，旧版本保留。
