# 交付清单

## 应用与代码

- `start.bat`：一键启动数据库、后端、前端并打开浏览器。
- `stop.bat`：停止本项目后台进程。
- `rebuild.bat`：从原始包重新清洗并幂等导入 Neo4j。
- `test.bat`：运行数据和 API 集成验收。
- `backend/`：独立 FastAPI 后端及 Neo4j 查询。
- `frontend/`：Streamlit 前端、可点击和拖动的本地图谱组件。
- `scripts/`：清洗、导入、运行、测试及视频录制程序。
- `data/`：原始数据、使用条款、清洗数据和统计。

## 文档（Markdown）

- `README.md`：本机与新电脑启动说明。
- `docs/原分工与任务详情.md`：保留 PDF 原任务、分工及交付对照。
- `docs/架构与接口.md`：前后端结构、图谱模型、评分定义与返回字段。
- `docs/queries.cypher`：Neo4j 常用查询。
- `docs/数据说明.md`：来源、字段、清洗规则、统计和使用条件。
- `docs/测试记录.md`：实际验证记录与 20 部电影抽查列表。
- `docs/项目演示讲稿.md`：操作讲解和故障备用方案。
- `docs/论文讲稿与问答.md`：TransE 论文解读、实验出处、答辩问答。

PPT 已渲染逐页查看，结构和版面检查通过，未在桌面 PowerPoint 应用中做交互编辑测试。表格和文字保留为可编辑对象。

## 验收结果

66 项后端验收通过，全部 9,742 部电影关系和原始 CSV 一致。固定随机种子抽查 20 部电影，23 组推荐与独立集合算法排序一致。浏览器实际验证类型/标签/电影节点、推荐按钮、同名检索、无结果、无标签、无可推荐关系及统计页。完整停止后再次启动成功，图数据保留。

## 提交包

`MovieGraph_提交包.zip` 包含代码、数据、文档、PPT、视频和截图，不含 `.venv`、便携运行时或运行中的数据库文件。新电脑按 README 首次联网安装，桌面原项目已经准备好运行环境。

系统严格使用共同类型数加共同标签数，未训练 TransE。原论文的实验指标均注明来源，不作为本组复现实验成果。成员计划分工与本次统一实现的实际情况分别说明，未虚构六名成员贡献。
