# 从第一版升级

增加ratings和links。模型新增匿名用户和RATED，电影新增均分、人数及外部标识；新增评分/链接和用户推荐页面。版本指纹涵盖有效评分和链接，启动自动判断是否迁移。

1. 保存旧项目备份，在旧目录运行stop.bat。
2. 解压新版完整目录。相同电脑可复制已有Java21与Neo4j运行环境，虚拟环境优先重新创建。
3. 双击start.bat，等待新版评分导入完成，再打开18501。
4. 首页应显示610用户与100,836评分边，并出现“评分与链接”“用户推荐”页签。
5. 数据可修改data/raw四表，重启或运行rebuild.bat。旧数据版本保留，计数限定当前版本。

源码包不包含虚拟环境和数据库运行文件。GitHub更新采用普通提交推送，保留历史，不强制改写远端。
