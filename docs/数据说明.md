# 四表数据来源与清洗

MovieLens Latest Small / GroupLens，来源README保存在data/raw/README.txt，使用须遵循其中条件。来源 https://grouplens.org/datasets/movielens/latest/ 。

movies用于电影和类型，tags用于归一标签，ratings用于匿名用户及评分时间关系，links用于外部编号属性。完整清洗规则详见项目报告。sourceSHA256记录每个输入文件，dataset包含四表有效内容。原始CSV优先，ZIP只补缺失文件。

9,742电影、19类型、1,475标签、610用户；22,050 IN_GENRE、3,574 HAS_TAG、100,836 RATED。IMDb覆盖9,742、TMDb覆盖9,734。8个缺失TMDb不补造。评分UTC时间与均分只属于该数据集。标签作者未建立关系，演员导演未抓取。
