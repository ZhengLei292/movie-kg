# TransE 论文分享：讲稿与问答

论文：Antoine Bordes, Nicolas Usunier, Alberto Garcia-Durán, Jason Weston, Oksana Yakhnenko. **Translating Embeddings for Modeling Multi-relational Data**. NIPS 2013, pp. 2787–2795。

原文：https://papers.nips.cc/paper/5071-translating-embeddings-for-modeling-multi-relational-data.pdf 。本目录保留用于阅读核对的原文。以下实验结果均引用原论文，**本项目未训练或复现 TransE**。

## 逐页讲稿（建议 7–9 分钟）

### 1. 论文主题

这篇论文研究多关系知识图谱的表示学习。输入是实体和关系构成的三元组，目标是预测缺失的头实体或尾实体。模型希望用很少的参数学习可用于补全知识库的表示。

### 2. 链接预测

设三元组为 `(h,r,t)`，例如一部电影具有某种类型。给定头实体和关系，把候选尾实体逐个评分，再排序。这里预测的是图谱中可能缺失的事实，与我们根据已存在关系找相似电影有不同的任务目标。

### 3. 平移思想

TransE 给每个实体和关系一个 k 维向量，真实关系应满足 `h+r≈t`。三元组能量为 `d(h+r,t)`，论文选 L1 或 L2 距离。距离越小越符合模型，不能与本项目“分数越大共享关系越多”的规则混淆。

### 4. 正负样本和训练

从真实三元组抽样，随机替换头或尾构造损坏三元组，一次只替换一端。训练目标是让真实三元组能量至少比负例低一个间隔：`max(0, γ+d_pos-d_neg)`。论文使用小批量随机梯度下降，每轮归一化实体向量到单位 L2 范数，通过验证集选择参数和早停。原文算法1与公式1、2给出细节。

随机替换出的三元组不一定在现实中为假，知识图谱可能不完整。这是负采样的局限，不应把所有未观测三元组都称作已经证实的错误事实。

### 5. 实验数据与评价

原文表2中，WN 包含 40,943 个实体、18 种关系，训练/验证/测试分别为 141,442/5,000/5,000；FB15k 为 14,951 个实体、1,345 种关系，483,142/50,000/59,071；FB1M 含约一百万实体、23,382 种关系、1,750 万训练事实。

对每个测试三元组分别替换头和尾为全实体集合候选。Mean Rank 是正确实体平均排名，越低越好。Hits@10 是正确实体进入前十的比例，越高越好。

Raw 直接对候选排序；Filtered 排除训练、验证、测试中已经存在的其他正确三元组，保留正在评价的目标，避免把另一条正确事实误当错误竞争项。这并不能消除所有未观测真实事实的问题。

### 6. 原论文主要结果

原文表3：WN 的 TransE Raw/Filtered Mean Rank 为 263/251，Hits@10 为 75.4%/89.2%；FB15k 为 243/125 和 34.9%/47.1%；FB1M 仅列 Raw：Mean Rank 14,615，Hits@10 34.0%。这些数字来自 2013 年论文及其比较设置，不能据此声称当前最先进，也不能称为本组实测。

### 7. 局限

平移假设简洁、参数量低，但表达能力受限。若同一头实体与关系对应多个尾实体，则严格的 h+r=t 会把多个尾实体推向同一位置。一对多、多对一、多对多关系可能出现表示冲突。原论文表4按关系基数区分评价，并未在每个子类别都优于所有对照。原文第3节还讨论其在依赖三元交互的 Kinships 数据上表现不够理想。

### 8. 与本系统的联系

我们的节点和关系可以导出为三元组，未来可以尝试用嵌入补全关系。但本系统仅两类关系，标签稀疏，需要认真设计数据划分、候选实体类型约束、负例和基线，防止把同一事实通过重复记录泄漏到训练与测试。训练预测与展示证据应分开：模型预测的边不能未经确认就显示成数据中已存在的关系。

## 预期问答

**问：为什么不用电影名称做唯一标识？**
答：数据中存在完全同名记录。movieId 提供稳定身份，标题只是展示属性。

**问：本项目是不是 TransE 推荐？**
答：系统使用共同类型和标签的计数推荐。TransE 是单独阅读分享的知识图谱嵌入方法，尚未训练或集成。

**问：距离小与推荐分数高矛盾吗？**
答：两者定义不同。TransE 能量越小表示三元组越符合平移假设；本项目分数越高表示两部电影共享事实更多。

**问：为什么要归一化实体向量？**
答：约束实体范数，防止通过无意义扩大向量范数降低间隔损失。论文在算法中每轮归一化实体，关系只在初始化时归一化，不应说每轮同时归一化所有关系。

**问：负例一定真实吗？**
答：随机替换构造的是训练负样本，可能包含未记录的真实事实，所以不保证每个负例在现实中确实为假。

**问：Filtered 是否等于只与错误候选比较？**
答：它只过滤数据集中已知的其他真三元组，知识库不完整时仍可能保留未知真事实。

**问：为什么一对多关系困难？**
答：同一 h+r 要接近多个不同尾实体，可能将本应区分的尾实体挤到相近位置。实际效果取决于其他关系的约束和优化。

**问：能不能说 89.2% 是推荐准确率？**
答：不能。它是原论文 WN 链接预测的 Filtered Hits@10，不是本电影系统的推荐准确率。
