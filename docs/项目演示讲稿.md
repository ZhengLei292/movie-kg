# MovieGraph 2 当场演示

先停止旧项目，运行新版start.bat，看到READY打开网页，再打开PPT。提前试跑，约十万条评分边首次导入比旧版慢。接口文档、Neo4j页、备用视频提前准备。

1. 首页说明四表全部接入，9,742电影、610用户、100,836评分边。
2. 搜索toy story选择#1，关联电影调到1、评分用户调到3。解释类型、标签、用户和RATED。
3. 右侧Toy Story 2共享5类与pixar，得6分，解释特征数量不是预测评分。
4. “评分与链接”展示均分、人数、分布与UTC历史。IMDb/TMDb来自links，外部站点需要网络。
5. “用户推荐”选择匿名用户1，说明共同高分邻居、支持人数先去重、排除已评分电影。
6. 点击用户推荐进入电影详情，数据概览解释总关系含评分边。
7. 切回PPT讲验收与局限，尚未评价推荐质量。结束运行stop.bat。

追问口径：userId是匿名来源编号，没有真实姓名和登录。缺失外部ID不补造，links以属性存储。旧版25,624是特征边，新版126,460包括RATED。业务节点11,846，状态另计。没有训练NER、图嵌入或深度模型。
